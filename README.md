## 🚀 نصب سریع

روی سرور **Ubuntu 24.04** (یا Debian) این دستور رو بزن:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/YOUR_USER/tgbot/main/install.sh)
```

منوی نصب باز می‌شه:

```
   ┌─────────────────────────────────────────┐
   │   TG Leech Bot  ·  Telegram → GitHub    │
   └─────────────────────────────────────────┘

    1) Install
    2) Update
    3) Edit config (tokens, repo, …)
    4) Uninstall
    5) Logs
    0) Exit
```

گزینه‌ی **۱** رو بزن. اسکریپت خودش این کارها رو می‌کنه:

1. پیش‌نیازها رو نصب می‌کنه: `python3`، `ffmpeg`، `7-Zip`، `megatools`، `git` و `deno` (برای یوتیوب)
2. کد رو کلون می‌کنه و محیط مجازی پایتون می‌سازه
3. **متغیرها رو ازت می‌پرسه** و اعتبارشون رو چک می‌کنه (توکن ربات، دسترسی به ریپو...)
4. سرویس `systemd` می‌سازه و ربات رو اجرا می‌کنه
5. دستور `tgbot` رو برای مدیریت بعدی نصب می‌کنه

### 🔑 متغیرهایی که پرسیده می‌شه

| متغیر | از کجا بگیرم؟ |
|---|---|
| `API_ID` و `API_HASH` | وارد [my.telegram.org](https://my.telegram.org) شو ← **API development tools** |
| `BOT_TOKEN` | از [@BotFather](https://t.me/BotFather) یه ربات بساز و توکنش رو بردار |
| `ADMIN_ID` | آیدی عددی خودت؛ به [@userinfobot](https://t.me/userinfobot) پیام بده. فقط همین کاربر می‌تونه از ربات استفاده کنه |
| `GITHUB_TOKEN` | [Settings ← Developer settings ← Tokens](https://github.com/settings/tokens): نوع Classic با دسترسی `repo`، یا Fine-grained با **Contents: Read and write** |
| `GITHUB_REPO` | ریپویی که فایل‌ها توش آپلود می‌شه، به شکل `username/repo` |

> [!IMPORTANT]
> - ریپوی آپلود باید **حداقل یک کامیت** داشته باشه (مثلاً یه `README`)، وگرنه ساخت Release خطا می‌ده.
> - اگه ریپو **عمومی** باشه، لینک فایل‌ها برای همه قابل دانلوده. برای فایل‌های شخصی یه ریپوی **خصوصی** بساز.
> - بهتره ریپوی آپلود جدا از ریپوی کد ربات باشه.

### ⚡ نصب بدون سوال (برای اسکریپت‌نویسی)

```bash
API_ID=123 API_HASH=... BOT_TOKEN=... ADMIN_ID=123 GITHUB_TOKEN=... GITHUB_REPO=user/repo \
  bash <(curl -fsSL https://raw.githubusercontent.com/YOUR_USER/tgbot/main/install.sh) install
```

## 🧭 مدیریت با دستور `tgbot`

بعد از نصب، از هر جای سرور:

| دستور | کار |
|---|---|
| `tgbot` | منوی تعاملی |
| `tgbot update` | آپدیت کد و نیازمندی‌ها و ری‌استارت |
| `tgbot config` | ویرایش متغیرها (توکن، ریپو و...) و ری‌استارت |
| `tgbot uninstall` | حذف سرویس (و در صورت تأیید، فایل‌ها) |
| `tgbot ytdlp` | فقط آپدیت yt-dlp |
| `tgbot logs` | لاگ زنده |
| `tgbot status` · `start` · `stop` · `restart` | کنترل سرویس |

## 🔄 آپدیت

سه راه داری، هرکدوم رو خواستی:

- **از سرور:** `tgbot update`
- **از داخل تلگرام:** `/update` (نسخه‌ی جدید رو می‌گیره، نیازمندی‌ها رو نصب می‌کنه، ری‌استارت می‌شه و تغییرات رو نشونت می‌ده)
- **فقط yt-dlp:** `/upgrade` در تلگرام یا `tgbot ytdlp`؛ وقتی یوتیوب یا اینستاگرام خطا داد اول این رو بزن

> فایل‌های `.env`، کوکی‌ها و نشست تلگرام توی گیت نیستن و موقع آپدیت دست نمی‌خورن.

## 🤖 دستورهای ربات

| دستور | توضیح |
|---|---|
| `/start` · `/help` | معرفی و راهنما |
| `/status` | وضعیت سرور: دیسک، نسخه‌ها، ابزارها، کوکی‌ها |
| **لینک یا فایل** | بفرست؛ نوعش تشخیص داده می‌شه |
| `/url لینک` | مثل ارسال لینک (نام دلخواه در خط دوم) |
| `/batch نام` | صف گروهی؛ هر مورد جدا در یک Release |
| `/batch zip` | همه در یک ZIP؛ شکل‌های دیگه: `/batch zip نام` · `/batch zip 1234 نام` · `/batch zip -p 1234` |
| `/pop` · `/done` | حذف آخرین مورد صف · شروع پردازش صف |
| `/zip` · `/zip 1234` | فایل/لینک بعدی زیپ بشه (بدون رمز / با رمز) |
| `/files` | ۱۰ Release آخر با دکمه‌های تغییر نام و حذف |
| `/search کلمه` | جستجو بین فایل‌های آپلودشده |
| `/cookies` | وضعیت کوکی‌ها و راهنما |
| `/cancel` | لغو کار جاری و پاک‌کردن صف و حالت‌های موقت |
| `/upgrade` | آپدیت yt-dlp |
| `/update` | آپدیت ربات از گیت‌هاب و ری‌استارت |

### ✏️ پنج راه تغییر نام

1. **قبل از ارسال:** اسم رو بفرست، بعد فایل/لینک
2. **حین دانلود:** اسم جدید رو توی چت بفرست
3. **خط دوم لینک:** لینک رو بفرست و توی خط بعدش اسم رو بنویس
4. **کپشن فایل** ارسالی
5. **دکمه‌ی ✏️ بعد از آپلود** (روی خود گیت‌هاب؛ فقط حروف انگلیسی، عدد و `._-` می‌مونه)

## 🍪 کوکی یوتیوب (و بقیه‌ی سایت‌ها)

یوتیوب IP سرورها رو اغلب «ربات» تشخیص می‌ده و خطای `Sign in to confirm you're not a bot` می‌ده. راهش دادن کوکیه:

1. توی مرورگر یه پنجره‌ی **Incognito / Private** باز کن و وارد حسابت شو (بهتره یه **اکانت جدا** باشه، نه اکانت اصلی)
2. افزونه‌ی **Get cookies.txt LOCALLY** رو نصب کن و از همون پنجره **Export** بزن
3. پنجره رو **ببند** (وگرنه یوتیوب کوکی‌ها رو عوض می‌کنه و فایل از کار می‌افته)
4. فایل `cookies.txt` رو همین‌طوری برای ربات بفرست

ربات خودش تشخیص می‌ده برای کدوم سایته (یوتیوب، اینستاگرام، توییتر، ساندکلاد)، ذخیره‌اش می‌کنه و **پیام فایل رو از چت پاک می‌کنه**. فایل کوکی هیچ‌وقت به گیت‌هاب آپلود نمی‌شه. وضعیت کوکی‌ها رو با `/status` یا `/cookies` ببین.

## 📦 فایل‌های بزرگ

گیت‌هاب هر فایل Release رو تا ۲ گیگ قبول می‌کنه. فایل‌های بزرگ‌تر خودکار به پارت‌های ۱۹۰۰ مگی تقسیم می‌شن:

```
video.mp4.zip.001
video.mp4.zip.002
```

**باز کردن:** همه‌ی پارت‌ها رو توی یه پوشه بریز، روی `.zip.001` راست‌کلیک کن ← **Extract** با 7-Zip یا WinRAR. روی لینوکس: `7z x video.mp4.zip.001`

یه فایل `links.txt` هم کنار پارت‌ها آپلود می‌شه که می‌تونی کامل به IDM بدی.

> روی اوبونتو ۲۴ ساخت ZIP چندبخشی با خود 7-Zip خطا می‌ده (`errno=17`)؛ این ربات ZIP رو یک‌تکه می‌سازه و خودش تقسیمش می‌کنه.

## 🛠 عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| `Sign in to confirm you're not a bot` | کوکی یوتیوب بده (بخش بالا) و مطمئن شو `deno` نصبه: `/status` |
| یوتیوب/اینستاگرام ناگهان خراب شد | `/upgrade` بزن و بعد دوباره امتحان کن |
| `Requested format is not available` | کیفیت دیگه‌ای انتخاب کن یا `/upgrade` |
| ساخت Release خطا می‌ده | ریپو خالیه (یه کامیت بساز)، یا توکن دسترسی نوشتن نداره |
| ربات جواب نمی‌ده | `tgbot logs` رو ببین؛ `ADMIN_ID` باید آیدی عددی خودت باشه |
| فضای دیسک تموم شد | `/status`؛ فضای خالی باید حدود ۲ برابر بزرگ‌ترین فایل باشه |
| توکن/ریپو رو عوض کردم | `tgbot config` |
| خطای `git pull` موقع آپدیت | تغییر محلی داری: `cd ~/tgbot && git stash` و دوباره `tgbot update` |

## 🗂 ساختار پروژه

```
tgbot/
├── install.sh          نصب‌کننده و منوی مدیریت (دستور tgbot)
├── main.py             نقطه‌ی شروع
├── core.py             کلاینت تلگرام و حالت مشترک
├── pipeline.py         دانلود ← ZIP ← ارسال/آپلود
├── jobs.py             صف کارها و مدیریت خطا
├── ui.py               کارت وضعیت و پیام‌های نتیجه
├── handlers/           دستورها، منوها، کوکی، مدیریت ریلیزها
├── services/           yt-dlp، گیت‌هاب، 7-Zip، ffmpeg، دانلودرها
└── utils/              نام‌گذاری، پیام‌های خطا
```

## 🔒 امنیت

- فقط `ADMIN_ID` می‌تونه با ربات کار کنه.
- `.env` با دسترسی `600` ذخیره می‌شه و توی گیت نیست؛ کوکی‌ها و فایل نشست تلگرام هم همین‌طور.
- توکن گیت‌هاب رو فقط به ریپوی آپلود دسترسی بده (Fine-grained token).
- کوکی حساب شخصی رو روی سرور نذار؛ یه اکانت جدا بساز.

## 📤 انتشار این پروژه روی گیت‌هاب‌ات

```bash
cd tgbot
sed -i 's|YOUR_USER/tgbot|نام‌کاربری/نام‌ریپو|g' README.md install.sh
git init -b main && git add . && git commit -m "init"
git remote add origin https://github.com/نام‌کاربری/نام‌ریپو.git
git push -u origin main
```

بعدش دستور نصب بالا (با آدرس خودت) روی هر سروری کار می‌کنه. اگه ریپوی کد **خصوصیه**، موقع نصب `REPO_URL=https://<TOKEN>@github.com/user/repo.git` رو هم به‌صورت متغیر بده.
